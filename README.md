# Tic-Tac-Toe Game 🎮

## About the Project
This is a simple two-player Tic-Tac-Toe game developed using HTML, CSS, and JavaScript.

I created this project while learning JavaScript through Shraddha Khapra's lectures.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Two-player gameplay (O and X).
- Automatic winner detection.
- New Game button.
- Reset Game button.
- Interactive 3×3 game board.

## How to Play
1. Open the game in your browser.
2. Player O starts first.
3. Players take turns selecting boxes.
4. The first player to get three marks in a row, column, or diagonal wins.
